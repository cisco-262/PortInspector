PRODUCT SUPPORT

How can we help?

Send enough context to reproduce the issue without including credentials or sensitive network data.

Before contacting support

  • Confirm that the target is inside a network you are authorized to inspect.
  • Try a longer timeout when Wi-Fi latency or endpoint load is high.
  • Check whether iOS Local Network access is enabled for Port Inspector Pro.
  • Record the unique report number if the question concerns a completed diagnostic.

What to include

Please include the Port Inspector Pro version, iPhone or iPad model, iOS version, scan mode, CIDR size, and a non-sensitive example. Do not send passwords, private keys, access tokens, or confidential addressing plans.

Contact

support@opshome.run

Responsible use

Port Inspector Pro is intended for diagnostic work on systems and networks you own or have explicit permission to test.
