专注诊断

从地址范围到可用证据。

选择 CIDR 目标和合适的检查层级，只保留有响应的服务，不再浏览成千上万条超时记录。

01

三种扫描模式

从核心服务开始，选择高级分类，或设置精简的自定义端口集合。

02

可控并发

可以调节探测并发数和超时时间，扫描引擎遵守固定的诊断预算。

03

按 IP 汇总

每个有响应的 IP 只占一个汇总区块，检测到的 TCP 和 UDP 服务直接显示在其下方。

04

可移交的报告

每次扫描都有唯一报告编号，并可导出为 CSV 或按 IP 分组的 PDF。

使用流程

更从容地检查子网。

  1. 01

    确定范围

    输入您拥有或已获授权检查的主机或 CIDR 地址段。

  2. 02

    选择信号

    使用基础、高级或自定义模式，并按需要调整超时或并发。

  3. 03

    本机运行

    设备直接执行诊断，无需 OpsHome 云端账户。

  4. 04

    查看报告

    完成后自动打开带编号的报告，展示统计、风险提示和按 IP 汇总的结果。

隐私优先

网络诊断留在本机。

Port Inspector 无需账户，也不会把扫描目标和结果上传到 OpsHome 后台。只有在您主动导出时，报告才会离开设备。

  • 诊断从您的 iPhone 或 iPad 直接运行
  • 有响应的结果保存在 App 私有容器内
  • 历史记录保留时间由您控制
